## 💻 Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd nama-repo-kamu
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Run the server**
   ```bash
   npm run dev
   ```
